# ex_arbete_2026

A chatbot that answers questions about the rules at Nordljus Consulting AB.
The company is made up. We test two versions, A and B, to see which one is better.

- `data/` - the rules and the test questions
- `src/` - the code
- `notebooks/` - run these in Databricks, 01 to 06
- `docs/` - our plan, our notes and our model choices
